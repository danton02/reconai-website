Exclusion Rules
Control which repair line items are hidden from the Most Common Repairs display. Excluded items are never removed from cost calculations — they still count toward your average reconditioning cost.
How exclusions work: Excluded items are filtered out of the Most Common Repairs list on every search result and dashboard widget — but their costs are still factored into your Average Reconditioning Cost. This keeps your estimate accurate while surfacing only meaningful repair patterns.
Applying Rules To
Exclusion rules apply across all stores in your group.
As Dealer Group Admin, rules you set here apply to the entire ABC Motors Group. Individual stores can have additional custom rules set by their Dealer Admin.
Add New Exclusion Rule
Contains: matches any description containing the word anywhere — e.g. "Inspection" matches "Used Vehicle Inspection", "CPO Inspection", "Multipoint Inspection"
Exact: matches only the exact string, case-insensitive — e.g. "Shop Supplies" matches "Shop Supplies" and "SHOP SUPPLIES" but not "Shop Supply Fee"
Starts With: matches any description beginning with the string — e.g. "CPO" matches "CPO Inspection", "CPO Certification", "CPO Detail"
